# *PIONTEREST* 

### Idea principal: 
Realizar una red social similar a Pinterest. Los usuarios son capaces de crear nuevas cuentas e iniciarlas. Ya en la aplicación, los usuarios pueden ver pines/fotos y subirlas, además de guardarlas en distintos tableros y asignarles nombres. Cada usuario tiene tambien su página de chat en la que los usuarios pueden unirse y mandarse mensajes, pines, imagenes y links, quedando guardado en la sala del chat.
La página principal muestra todos los pines que se hayan creado. Los usuarios pueden crear tableros compartidos. 

-  Problemática: 
Ser una forma de entretenimiento menos dopamínica y divertida, además de poder ver temas que te gustan y expresarte con las imágenes. 

-  Público objetivo: 
El público serían los adolescentes, ya que son los que usan este tipos de redes sociales. 

-  Objetivo general: 
Poder crear y enviar colecciones personalizadas de imágenes

### Las funcionalidades a ser desarrolladas son:  

- Colecciones: crearlas, guardar fotos en ellas, ponerle un nombre a la colección, designar usuarios que puedan editarla

- Fotos: poder “subir” fotos, asignarles tags, ver fotos de otros usuarios y su información y darle "me gusta". 

- Página: poder mostrar todas las fotos con tags específicos

### Principales funcionalidades y características esperadas: 
Inicio de sesión, registro y cerrar sesión; colecciones de fotos (y gif, si es posible); colecciones compartidas entre usuarios (cada uno puede añadir fotos); buscador por temas de fotos y/o por usuarios; chat entre usuarios; página de usuario admin (eliminar usuarios y pines).

Inicialmente el proyecto va a contar con 44 fotos, en total van a existir 4 temas (comida, memes, ropa, animales), y cada foto puede tener hasta 2 tags/temas.
